How does power get to the controllers?

Acceptance Criteria
Power box load
Total load must stay under 96 W.
Tape per controller
Total tape connected to one controller must stay under the limit for the selected tape style.
Tape length
A run powered from one end should be 16.4 ft or less. If powered from both ends, it is modeled as two half-length feeds.
Start of Tape
Estimated light loss before the tape begins. This is affected by wire length, wire size, and total load.
Start to End of Tape
Estimated brightness difference from the start of the tape to the far end of the tape.
Result ranges
Under 25% is within recommended range. 25-40% may be visible. Over 40% is not recommended.
