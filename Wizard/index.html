Lutron Lumaris + Rania

T.R.A.C.E. Tool

Tape Run Assessment and Compliance Engine

Plan your Lumaris or Rania tape light job before you install it. Enter the tape runs, choose the product, and T.R.A.C.E. checks the recommended power supplies, controllers, power wire limits, control wire limits, and setup limits.

Acceptance Criteria
Power box load
Total load must stay under 96 W.
System assumption
This tool assumes Rania or HomeWorks Multi-Channel Wireless Controllers with a 96 W power interface.
Tape per power interface
Total tape across all enabled controllers on the same 96 W power interface must stay under the selected tape style limit.
Tape length
Lumaris and Rania Long Run should feed both ends or split above 16.4 ft. Rania High Output should feed both ends above 11 ft.
Suggested distances
Each controller is checked with voltage-drop math across the actual power path and control path. Installed control wire footage is shown for ordering, but Good / Review / Fix is based on the electrical path to the tape.
Planned distances
Enter the actual power-to-controller distance and controller-to-tape control wire distance to check the final placement.
Result ranges
Under 25% is good. 25-40% may be visible. Over 40% is not recommended.
