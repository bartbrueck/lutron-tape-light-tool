T.R.A.C.E. Tool

Tape Run Assessment and Compliance Engine

Plan your Lumaris or Rania tape light job before you install it. Enter the tape runs, choose the product, and T.R.A.C.E. checks the recommended power supplies, controllers, maximum wire distances, and setup limits.

Assumption: this tool is based on Rania or HomeWorks Multi-Channel Wireless Controllers used with a 96 W power interface.

Acceptance Criteria
Power box load
Total load must stay under 96 W.
System assumption
This tool assumes Rania or HomeWorks Multi-Channel Wireless Controllers with a 96 W power interface.
Tape per power interface
Total tape across all enabled controllers on the same 96 W power interface must stay under the selected tape style limit.
Tape length
Lumaris and Rania Long Run should feed both ends or split above 16.4 ft. Rania High Output should feed both ends above 11 ft.
Suggested distances
Each run shows a good total wire path and a max total wire path based on the selected wire sizes and load.
Planned distances
Enter the actual power-to-controller and controller-to-tape distances to check the final placement.
Result ranges
Under 25% is good. 25-40% may be visible. Over 40% is not recommended.
